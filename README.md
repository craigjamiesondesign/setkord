# Setkord redesign reference

Public working reference for a presentation, layout and motion redesign of [setkord.com](https://setkord.com/).

## Preview

The captured website is published with GitHub Pages at:

`https://craigjamiesondesign.github.io/setkord/`

## Repository structure

- `docs/`: Pages-ready static mirror containing the editable HTML, CSS, JavaScript and public assets.
- `reference/SITE-MAP.md`: page inventory, observed interactions and capture limitations.
- `reference/manifest.json`: captured URL-to-file manifest.
- `reference/screenshots/`: verified desktop and mobile homepage captures.
- `CLAUDE-HANDOFF.md`: context and working instructions for Claude.

## Important limitations

This is a capture of deployed Next.js output, not the private source repository. Authentication, account features, contact-form submission and Cloudflare Turnstile require the live service. See `reference/SITE-MAP.md` for details.

No changes in this repository are deployed to the live Setkord website.
